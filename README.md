# input-output-bot
Input Output Bot for MODS (Math Olympiad Discord Server)

Start by running pip install -r requirements.txt and pip install -r requirements_dev.txt (if dev)

add a token.yml with content like token: 'TOKEN-HERE' and never commit this (it should be in .gitignore)

If ur non-collaborator:
go to Discord Developer Portal and make a bot, invite bot to ur private server, take its token and put it into the token.yml

If ur collaborator:
just use the same bot if u want, ill give u the token so you can just add that to your token.yml
